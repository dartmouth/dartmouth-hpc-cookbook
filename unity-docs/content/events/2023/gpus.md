Unity facilitator Connor Kenyon of the University of Massachusetts Dartmouth will present a workshop on the available GPU resources on Unity. During this workshop, participants will gain experience accessing and utilizing a GPU in both interactive Jupyter sessions as well as with SLURM. Talking points will include requesting an overview of available resources, accessing GPUs on Unity, and a brief introduction to available GPU accelerated software as well as tools for profiling GPU code. This workshop will provide direct practical experience by setting up a Jupyter notebook environment for popular machine learning software such as PyTorch and tensorflow on the Unity OnDemand interface. This workshop will be held remotely via Zoom. Please register for a Unity account prior to the workshop if you do not already have one by visiting [the Unity Portal]({{< param account-base-url >}}).
