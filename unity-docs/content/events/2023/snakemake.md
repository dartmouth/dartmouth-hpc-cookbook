[Snakemake](https://snakemake.readthedocs.io/en/stable/) is a workflow engine for piping data through analysis pipelines. While particularly popular in the bioinformatics community, Snakemake is useful across any field that involves pipelines of data processing and analysis. This workshop will introduce using Snakemake on Unity and demonstrate a workflow on metagenomics data. This workshop will be held remotely via Zoom. Please register for a Unity account prior to the workshop if you do not already have one by visiting [the Unity Portal]({{< param account-base-url >}}).
