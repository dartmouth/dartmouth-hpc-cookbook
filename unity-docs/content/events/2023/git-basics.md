Git, a version control software, lets you retain a record of changes throughout the history of your software. Version control is essential for reproducible, traceable science and is useful for any field with a computational component. This workshop will introduce you to the fundamentals of version control with git and how to incorporate version control into your Unity workflow. This workshop will be held remotely via Zoom. Please register for a Unity account prior to the workshop if you do not already have one by visiting [the Unity Portal]({{< param account-base-url >}}).
