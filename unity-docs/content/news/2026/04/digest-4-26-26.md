Hi Unity Users! This week’s digest includes important information about Unity’s annual maintenance period and a new Python package manager…
<!--more-->

## 🔧 Unity’s Annual Maintenance Period
Unity, including login access and storage, will be offline from **June 15, 2026 at 5:00 pm Eastern through June 18, 2026 at 9:00 pm Eastern** for necessary maintenance and upgrades.

We will also be upgrading the firewall at MGHPCC on June 18 and expanding what is behind it, increasing security, ease of maintenance, and bandwidth.

More details were released via email today, and we encourage users to start planning accordingly for the maintenance period.

## ⚡ Python Package Manager `uv` is Now Available!
`uv` is a tool for installing Python packages and creating virtual environments where you can specify the Python version. If you currently use `conda` environments, try `uv` as another method to install your own Python version!

To access `uv`, run `module load uv/latest`.

## 🪫 MGHPCC Power Outage on April 19
We appreciate your patience during the MGHPCC power outage on April 19. A big thank you to our system admins, who were able to return Unity to service in under four hours!

If anything in Unity is still not working as expected as a result of the outage, contact the [Unity Community Slack’s](https://docs.unity.rc.umass.edu/contact/community/) #help-desk channel or email [hpc@umass.edu](mailto:hpc@umass.edu).
