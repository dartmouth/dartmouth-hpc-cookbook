## 🧠 New Unity OnDemand Application: RShiny
**Shiny** is a web framework for creating interactive dashboards. Use it to develop, deploy, and share applications for data processing, visualization, and reporting. RShiny OnDemand application allows users to launch Shiny applications on Unity with ease.

To get started, enter either the directory containing your application or the GitHub repository with the application in its root directory, then click **Launch**.

## 🔬 New Science Applications on Unity Desktop Environments
We've added two new GUI applications to Unity Desktop Environments ([Schrödinger 2025-2](https://www.schrodinger.com/life-science/) and [UCSF Chimera](https://www.cgl.ucsf.edu/chimera/index.html)), along with convenient access to them in the **Application Finder** (🔍) and the **Startup** menu under the **Science** tab.
