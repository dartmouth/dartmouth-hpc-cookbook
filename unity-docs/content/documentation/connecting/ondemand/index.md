# Connect to Unity via Unity OnDemand

The simplest and most convenient way to connect to Unity is through 
[Unity OnDemand]({{< param ood-url >}}).

Unity OnDemand allows you to **sign in on your browser using your organization's identity provider**, so don't need to install SSH, configure SSH, or set up any public and private keys. The following instructions will show you how to access the Unity login shell.

## Access the Unity login shell
1. Login to [Unity OnDemand]({{< param ood-url >}}) with your 
organization's identity provider. 
2. From the top menu, click **Shell**.
3. In the dropdown menu that appears, click **Unity Shell Access**.

{{< figure src="ood-shell-button.png" title="OnDemand Shell button" alt="OnDemand Shell button" >}}


The Unity login shell window appears with the large `Unity` logo at the top, as shown below:

{{< figure src="ood-shell.png" title="OnDemand Shell" alt="OnDemand Shell" >}}


To customize the theme of the shell, click the drop-down menu next to **Themes**.

{{< figure src="ood-shell-themes.png" title="OnDemand Themes" alt="OnDemand Themes" >}}
